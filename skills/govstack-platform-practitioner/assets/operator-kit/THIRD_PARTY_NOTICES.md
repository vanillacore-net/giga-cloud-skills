# Third-party notices

This kit distributes VanillaCore learning-lab wrappers and documentation, not an upstream Kubernetes installation bundle or executable image. Bootstrap, Dashboard, charts, cloud tools and images are obtained separately through their approved sources and retain their upstream terms.

Python runtime dependencies are PyYAML (MIT) and Jinja2 (BSD-3-Clause), installed separately at versions in lab/requirements.txt. The optional hashicorp/http-echo image is digest-pinned in lab/VERSIONS.yaml; no image binary is shipped. Consult each project's license and notices before redistribution. SOURCE.md records the lab commit and both implementation references. MANIFEST.sha256 covers the exact final distributed files.
